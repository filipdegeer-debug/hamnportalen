# Hamnportalen

Hamnportalen är ett React-projekt för att hantera svenska hamnanläggningar.

## Funktioner

- Interaktiv karta över Sverige
- Hamninformation
- Kundmarkeringar
- Dokumenthantering (kommer)
- GISIS (kommer)
- CER/NIS2 (kommer)

## Teknik

- React
- Vite
- Leaflet
- Git
- GitHub

## Starta projektet

Installera beroenden:

```bash
npm install
```

Starta utvecklingsservern:

```bash
npm run dev
```

Öppna sedan:

http://localhost:5173
```
